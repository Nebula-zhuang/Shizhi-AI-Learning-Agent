## 〇、先说方向判断

你列的禁忌项（蓝紫渐变、满屏卡片、仪表盘模板感、巨大数字、无意义装饰）恰好是 v1 **已经避开**的。
v1 真正缺的不是配色，是三样东西：

| 缺什么 | 表现 | v2 怎么补 |
|---|---|---|
| **空间** | 所有东西都"一样近"，纸贴在页上 | 四级表面 + 四级高程，建立"浮起/下沉"的语言 |
| **光** | 页面被均匀照亮，没有视线引导 | 极淡暖光池 + 焦点/生成态的外发光 |
| **动势** | 界面是静的，切换是硬切 | 统一时长与缓动，页面/卡片/节点各有入场 |

所以方向定的是你自己给的关键词 —— **editorial + technology**：
**保留暖纸与衬线的编辑气质，补上光影、纵深与动势**。不是换皮，是把二维纸面变成一间有光的书房。

## 一、设计系统

### 令牌（`src/styles/theme.css`，724 行）

**新增的层：**

| 类别 | 内容 |
|---|---|
| 画布与氛围 | `canvas` / `halo-warm` / `halo-cool` —— 两团极淡暖光，`background-attachment: fixed`（光属于"房间"，不跟着纸滚动） |
| 表面（4 级） | `surface-1/2/3` + `glass` / `glass-strong` —— **玻璃只给浮层**，内容卡一律实心 |
| 高程（5 级） | `e0–e4`，每级三层叠加（贴地接触影 + 中距扩散 + 远距环境影）—— 单层阴影永远"假" |
| 光晕 | `glow-moss` / `glow-sienna` / `glow-soft`，只给激活、焦点、生成中 |
| 间距 | `space-0-5` → `space-20`（4px 基准）+ 布局常量（侧栏/内容宽/阅读行宽） |
| 动效 | `dur-instant→slower` 五档 + 四种缓动（含只给"出现"用的 `ease-spring`） |

**两条硬约束（不因为好看而让步）：**
1. **光只能服务内容**，不透明度上限压得很低，且**永不放在文字下面**。任何让正文对比度掉下 4.5:1 的光晕就是错的。
2. **玻璃只给浮层**。整站玻璃会同时毁掉可读性和质感 —— 玻璃一多，就没有"玻璃"了。

**一处自我纠正**：第一版暖光池给了 `0.1` 不透明度，整页泛成一片橙、像蒙了层脏玻璃。
实测截图后压到 `0.05` —— 现在是"单看察觉不到，去掉后立刻觉得平了"。

### 暗色主题

**不是把亮色反相**：暖纸 → 深褐灰（不是纯黑、也不是蓝黑），墨色 → 暖象牙白，主色提亮以保证暗底对比度。

**默认亮色、不跟随系统。** 跟随 `prefers-color-scheme` 是常见做法，这里刻意不用：
产品身份是在亮色下建立的，若首屏长什么样取决于用户系统怎么设，这个身份就不成立 —— 演示时更不该"打开是黑是白看运气"。用户手动切过就记住。

## 二、组件库（`src/ui/`，共 1,202 行）

**为什么要先建这一层**：v1 的问题不在配色，在**碎片化** —— 同一个"次要标签"在四个文件里有四种写法，圆角、内距、字号都差一点。单看每处都不明显，叠起来就是"不精致"。

| 文件 | 内容 |
|---|---|
| `icons.tsx` | 30 个手写 SVG 图标。**不引图标库** —— 统一 1.5px 描边、圆头圆角、24 网格；混进任何第三方图标集都会在字重上和正文打架（最常见的"廉价感"来源） |
| `primitives.tsx` | Button（4 变体×3 尺寸）/ Badge（5 调性）/ Card / SectionTitle / SegmentedControl / Progress / Ring / Tooltip / Switch / CheckMark / **ThemeProvider** |
| `states.tsx` | Skeleton（含整页骨架）/ EmptyState / ErrorState / Pulse / Thinking / SuccessMark |
| `overlays.tsx` | **Toast**（成功 2.6s、出错 5s —— 出错要留够读完的时间）/ Modal（Esc、锁滚动、焦点移入） |

**一条刻意遵守的规则**：组件只管"长什么样"，不管"放在哪"。外距一律由使用处决定 —— 组件自带 margin 是布局失控的开始。

## 三、信息架构

从**顶部三标签**改为**侧边栏工作台**：

```
拾知                    ← 品牌
────────────────────
今天                     ← 学习空间首页（新）
辅导                     ← Tutor
书房
  资料
  知识地图
────────────────────
我的                     ← 个人中心（新）
────────────────────
夜间 / 演示同学 / 退出
```

**为什么改侧边栏**：顶部标签是**网页**的骨架。空间感来自"有墙、有栏、有稳定的定位锚"——侧边栏常驻，内容区独立滚动，滚动时"我在哪"始终可见。而且侧边栏能容纳层级（分组 + 当前项 + 账号区），顶部标签只能平铺。

**命名上去掉了重复**：组标签叫「书房」、条目叫「资料」—— 若组标签也叫"资料"，导航里会连着出现两个"资料"。

**开发者入口彻底移出默认体验**（`?dev=1` 或 `Ctrl/⌘+Shift+D` 唤出）。

## 四、Tutor（投入最多的一页）

### 任务卡：把"我要回答什么"变成不需要寻找

后端提示词要求助教提问时写清「问什么／要答到／怎么答」。v1 直接当散文渲染 —— 能读，但学习者最需要的那一步要靠自己从段落里找。

v2 新增 `taskCard.ts`（190 行）**容错解析**，把问题渲染成三区块任务卡：

```
┌─ 现在的问题 ──────────────────────┐
│ 进程和线程，谁是资源分配单位？      │  ← 衬线大字，视觉重心
├─ 你需要回答 ──────────────────────┤
│ ① 哪个是"资源分配单位"             │
│ ② 哪个是"调度单位"                 │
├─ 怎么答 ─────────────────────────┤
│ 💡 用两个短句回答                  │
└───────────────────────────────────┘
```

**它的核心设计是"最差退化成原文，而不是显示错东西"**：
- 找不到明确问题句 → 返回 `null`，调用方渲染普通正文
- 有要点没引导语 → 仍出卡，只是少一个区块
- 任何异常都不抛，宁可退回散文

另有一个 `uncoveredLines()` 兜底：**万一某一行既没进引导语、也没进要点、也不是问题，会被捡回来而不是静默消失**。丢句子比排版难看严重得多。

### 反馈四段，顺序是刻意的

**先说对的，再说缺的** —— 反过来会让人一进门就看到"你错了"，后面的解释都不太读得进去：

1. 结论行（答对了/没答对 + 做得怎么样）
2. 对在哪、为什么
3. **没说到**（逐条列）
4. **理解偏了**（逐条列，用绛色点）
5. **接下来**：用前端按规则组的人话，不是后端写给系统看的理由

### 从三栏砍成一栏

v1 是「课程树 | 对话 | 状态」三栏。加了侧边栏之后，四个纵向区块挤在 1280px 里，**中栏只剩不到 500px —— 而中栏恰恰是要读长句子的地方**。这是拿阅读体验换"信息都在眼前"，换亏了。

v2 按"什么时候需要"重新分配：选知识点 → 选择器；正在学什么 → 常驻顶栏一条；对话 → 独享整宽。**对话区从不到 500px 变成接近 900px。**

作答框下方常驻一句：「回答后我会看你答到了哪几点，再决定是继续追问、换个讲法，还是提高难度。」

## 七、过程中修掉的真实问题

**① `GET /api/documents/{id}/knowledge-points` 一直在 500。**
我在资料归属改造时给这个路由加了一行 `document_service.get_document(...)`，**但忘了 import**。

它能在测试里活下来，是因为**这个端点此前完全没有覆盖**（测试只测了"知识点不存在"的 404 分支）。
已修，并补了 4 条覆盖测试 + 一个全路由导入完整性审计。

**教训**：凡是"改了但没测到"的分支，都会以这种方式回来找你。

**② 图谱配色写死色值。** `statusStroke` / `edgeStyle` 返回十六进制色值 —— 切到夜间模式它们会原地不动，成为整页里唯一"没跟上"的部分。已全部改成 CSS 变量。

**③ 一个测试在测"我上次写的字符串还在不在"。** 改令牌后 `graphLayout.test.ts` 红了，因为它断言 `statusStroke('未知') === '#d5cbbb'`。已改成断言**行为**（未知状态必须与"未校验"同档，且三个有结论的状态都不与它同色），并新增一条"必须引用设计令牌"的测试。

**④ 品牌标记硬编码色值**（`#1b6b54` / `#faf7f1`）—— 违反自家设计系统。已改用 `currentColor` / CSS 变量。

## 八、仍未完成 / 已知问题

1. **`接口调试` 页未重构** —— 它是开发者工具，不在普通用户体验里，本轮没投入。
2. **窄屏（768px 以下）只保证"不溢出"**，未做侧边栏折叠成图标栏的精细适配。比赛演示针对桌面端。
3. **知识地图的"视觉冲击力"还差一层** —— 目前是清晰、克制、可用，但没到"核心页面秀出来"的程度。可以再做的：节点按掌握度染色（目前只按校验状态）、关系边的聚合收放、进入地图时的整体编排动画。
4. **`DocumentDetail`（资料详情）未重写** —— 它沿用 v1 结构，已自动继承新令牌（`paper`/`field` 都保留为别名），观感与 v2 一致，但内部仍是旧写法。
5. **亮色下的"沉浸感"是克制的** —— 光池压得很暗。如果你希望首屏更有戏剧性，把 `--color-halo-warm` 从 0.05 提到 0.08–0.10 即可，但我建议不要超过 0.10（第一版就是 0.1，整页发橙）。
